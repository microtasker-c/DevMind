# Articles Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for scoped tasks; user instruction overrides skill commits/checkpoints: continue directly without committing or pushing.

**Goal:** 完成可验证邮箱用户的文章编辑发布，以及真实首页与公开详情。
**Architecture:** 服务端 Drizzle 事务与统一权限守护；分离文章元数据和 BlockNote 正文。使用既有技术栈，不增加核心依赖。
**Tech Stack:** Next.js 15 App Router, React 19, HeroUI 3, BlockNote 0.41, Drizzle PostgreSQL, Better Auth, Resend HTTP.
**Spec:** docs/superpowers/specs/2026-11-09-articles-design.md

## Global Constraints
- 保留用户已有未提交修改，不提交、不推送，不重置数据库。
- 首页与已发布详情公开；所有私有路由及写入要求邮箱验证；仅作者可编辑。
- 已发布文章手动保存后立即公开更新；封面在发布表单选填。
- 对高风险权限与数据校验先写测试再实现；UI 通过类型检查、构建与浏览器检查。
